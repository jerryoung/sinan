# QMT RPC 单实例安全脚本设计

## 目标

交付一份可整文件粘贴到大 QMT 模型的完整 `sinan_qmt.py`。保留 targets
批量执行、fills 回写、策略虚拟账本和实盘状态推送，同时解决 Windows 上多个
模型争用同一 RPC 端口时连接随机落到旧实例的问题。

## 配置语义

- `RPC_TOKEN = ""`、`RPC_ALLOW_IPS = []`，仓库不预填用户凭证或网络白名单；
  用户在 QMT 策略编辑器顶部配置区自行填写。
- `RPC_ALLOW_TRADE = False`，远端 RPC 默认只读；targets 定时执行不受影响。
- 非本机绑定必须同时具备非空 Token 与非空白名单，否则启动时立即报错。

## 监听与诊断

- Windows 使用 `SO_EXCLUSIVEADDRUSE` 独占端口；其他平台保持 `SO_REUSEADDR`，
  便于本地测试。
- 监听句柄登记在 QMT 进程级 `builtins` 注册表；模型热重启时先关闭上一代
  监听再绑定，避免必须重启整个 QMT 客户端。
- 启动日志打印实际脚本路径、生效白名单、监听地址和交易开关。
- 每次连接打印来源地址；白名单拒绝同时打印来源和生效白名单。
- Token 只打印长度，不打印内容。

## 验证

- 单元测试锁定默认只读、空 Token/白名单以及 Windows 独占监听选项。
- 既有 RPC 端到端、只读限制、Token 校验、IP/CIDR 白名单测试保持通过。
