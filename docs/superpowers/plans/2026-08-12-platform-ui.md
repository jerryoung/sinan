# 司南平台 UI 重设计实施计划

**目标：** 将选定的“策略研究工作台”视觉系统实现到全部 Streamlit 页面，
保持业务逻辑和配置契约不变，并通过浏览器设计 QA。

## Task 1：共享主题和应用外壳

- 新增 `ui/theme.py`：设计令牌、全局 CSS、页头、流程条、状态键值组件。
- 新增 `.streamlit/config.toml`：深色主题与图表主色。
- 修改 `app.py`：品牌资产、Material Symbols 导航、紧凑策略上下文。
- 先新增结构测试，再实现并验证。

## Task 2：策略研究工作台

- 重构 `ui/shadow.py` 为左分析画布 + 右决策栏。
- 保留净值、持仓、交易记录、targets、运行按钮及现有数据源。
- 右栏接入命名实盘配置、targets 数据截止与真实风控设置。
- 浏览器验证 1440 × 1024 主状态及空状态。

## Task 3：数据与回测流程页

- 回测页高亮回测阶段，压缩运行区与报告区层级。
- 行情、数据仓、数据更新页高亮数据阶段并统一指标带、图表和表格。
- Plotly 图表应用共享背景、字体和语义色。

## Task 4：配置与设置页

- 策略配置、系统设置、实盘配置统一页头、分区标题和操作栏。
- 删除仍为次要操作；默认或被引用配置仍禁止删除。
- 浏览器验证新增、编辑、设默认和删除保护控件仍可达。

## Task 5：设计 QA 与回归验证

- 同一 1440 × 1024 视口捕获选定参考和实现截图。
- 生成组合对比证据，按 P0/P1/P2 修复并写 `design-qa.md`。
- 检查七页控制台错误、导航和关键交互。
- 运行全量测试和代表性长区间回测；清理临时状态后提交。
